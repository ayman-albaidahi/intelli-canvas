# IntelliCanvas v0.8.0 — Image Quality Analyzer

## Scope

v0.8.0 introduces a unified, deterministic, read-only image quality report. The analyzer reports brightness, contrast, sharpness, noise, clipping, and a normalized quality score. It does not modify the current image or add History entries.

## Unified report

The report contains `analyzer_version`, `analysis_hash`, `cache_hit`, `metrics`, `findings`, and `quality_score`. Metrics preserve the original image dimensions while also exposing the reduced dimensions used for analysis. Large images are resized to a maximum analysis side of 1024 pixels to bound CPU and memory use.

Brightness uses grayscale mean and median. Contrast uses grayscale standard deviation. Sharpness uses normalized Laplacian variance. Noise is an estimate based on the residual between the grayscale image and a 3×3 Gaussian-smoothed image. Clipping is reported as the ratio of pixels at or below 3 and at or above 252.

The quality score combines brightness, contrast, sharpness, noise, and clipping sub-scores. It is a comparative product metric rather than a scientific image-quality measurement. Findings include severity and evidence so that downstream suggestions can remain explainable.

## Cache

Analysis cache keys are SHA-256 hashes of the source file bytes, analyzer version, and canonical analysis options. Results are stored as JSON under the runtime `analysis-cache` storage category. Changing the analyzer version invalidates old results automatically. Cache hits are reported to the client and do not affect History.

## API

```http
POST /api/analysis
```

```json
{
  "image_id": "...",
  "options": {}
}
```

The same unified report is used by `/api/analysis/export-report` and by Smart Suggestions. All endpoints validate the image session and return the standard error shape for missing or unavailable images.

## Frontend

The Image Intelligence panel displays the quality score, dimensions, brightness mean and median, contrast, sharpness, noise, shadow clipping, and highlight clipping. Findings are rendered using stable finding codes and the analyzer cache state is announced in the status region.

## Verification

The release includes analyzer correctness tests for metric shape and findings, cache hit behavior, read-only image and History behavior, and unified export reports. The full validation run passed 225 Python tests, Ruff, JavaScript syntax checks, Vitest, and `git diff --check`.
