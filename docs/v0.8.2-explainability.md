# IntelliCanvas v0.8.2 — Explainability

## Scope

v0.8.2 makes Analyzer and Smart Suggestions decisions inspectable. It adds a deterministic Explain Operation API, human-readable explanations for every analyzer finding, parameter explanations, suggestion source provenance, and evidence rendering in Image Intelligence.

## Explain Operation API

```http
POST /api/explain-operation
```

```json
{
  "operation": "brightness",
  "parameters": {"value": 130},
  "finding": {
    "code": "LOW_BRIGHTNESS",
    "severity": "high",
    "evidence": {"brightness_mean": 25, "target_range": [110, 180]}
  },
  "source": {
    "kind": "smart-suggestion",
    "suggestion_id": "BRIGHTNESS_BOOST",
    "rule_version": "0.8.1"
  }
}
```

The response explains the operation, each supplied parameter, the related finding, the reason, and the source. Operation and parameter validation reuse the Pipeline validation contract, so explanations cannot be generated for invalid operations or unsafe parameters.

## Finding explanations

Analysis and Suggestions responses now enrich each finding with a title, explanation, severity, and evidence. The evidence remains structured JSON so clients can render or inspect it without parsing human-readable text.

## Suggestion provenance

Smart Suggestions expose their source findings, rule-engine version, evidence, reason, and Pipeline nodes. The frontend displays which findings caused the suggestion, the confidence evidence, and every operation parameter before Preview or Apply.

## Frontend behavior

The Image Intelligence panel displays expanded finding cards, evidence blocks, suggestion source information, and Pipeline parameter JSON. Preview remains read-only and Apply retains the v0.8.1 behavior of producing one History entry for the selected Pipeline.

## Verification

The release adds tests for operation explanations, parameter explanations, finding explanations, suggestion provenance, invalid parameter handling, and report evidence. The full validation run passed 231 Python tests, Ruff, JavaScript syntax checks, Vitest, and `git diff --check`.
