# IntelliCanvas v0.8.1 — Smart Suggestions

## Scope

v0.8.1 extends the deterministic v0.8.0 analyzer into an explainable Smart Suggestions rule engine. Suggestions are generated from analyzer findings, expose confidence and evidence, and carry a validated Pipeline definition that can be previewed or applied.

## Rule engine

The rule engine version is `0.8.1`. Current rules cover low brightness, low contrast, high brightness, low sharpness, and high noise. A combined exposure-and-contrast rule is emitted when both low brightness and low contrast are present. Sharpen is suppressed when high noise is present to avoid amplifying artifacts.

Every suggestion includes:

- `id` and `type`.
- Human-readable `title` and `reason`.
- `confidence` normalized to 0–1.
- `evidence` copied from the analyzer report.
- `source_findings`.
- `rule_version`.
- A Pipeline definition with one or more validated nodes.
- A backward-compatible `suggested_operation` summary.

## Pipeline integration

Suggestion Preview invokes the same fixed-source Pipeline executor used by v0.7.2. Preview returns a PNG and does not modify the current image or History. Suggestion Apply invokes the same executor with `persist=true`, so a multi-node suggestion creates exactly one `Apply pipeline` History entry.

Apply History parameters include the Pipeline hash, source History index, suggestion source, suggestion ID, and rule-engine version. This makes the result auditable and reproducible. The Pipeline cache is shared with ordinary Pipeline apply operations.

## User experience

The Image Intelligence panel now renders multiple selectable suggestions. Each card shows its title, confidence, and Pipeline step count. Selecting a card opens its reason and evidence context, then exposes Preview, Dismiss, and Apply actions. Dismiss removes the selected card from the current view without changing the image.

## API behavior

`POST /api/suggestions` returns the analyzer metadata, findings, and all available suggestions. `POST /api/suggestions/preview` renders the selected suggestion Pipeline without persistence. `POST /api/suggestions/apply` applies the selected Pipeline and returns the applied image metadata, Pipeline, cache state, and compatibility operation summary. Invalid suggestion Pipelines return the standard `INVALID_PIPELINE` error shape.

## Verification

The v0.8.1 suite covers multiple suggestions, confidence bounds, evidence, combined Pipelines, read-only Preview behavior, one-entry Apply History behavior, suggestion provenance metadata, previous suggestion compatibility, Ruff, JavaScript syntax, Vitest, and the full regression suite. The final run passed 227 Python tests and 3 Vitest tests.
